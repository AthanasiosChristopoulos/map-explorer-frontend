===============================================================================================================

GeoJSON - Is basicly a JSON, which follows a specific schema:

    Mapbox needs to know for each object:
        - What each object represents (via "type", πχ "Feature")
        - Where it is on the map ("geometry" => coordinates, type (a point))
        - What data it carries ("properties" => meta data about each pin)

    Mapbox types:
        - "Point" → one single location:
                let lng = data.geometry.coordinates[0];
                let lat = data.geometry.coordinates[1];

        - "Feature" → a single object with geometry (location) + properties.
        - "FeatureCollection" → an array of Features, i.e. multiple locations with metadata.
    
    icon-allow-overlap = false => a pin is skipped when it collides with one already drawn.
    icon-ignore-placement = false => a pin can be skipped because of other layers’ icons.
